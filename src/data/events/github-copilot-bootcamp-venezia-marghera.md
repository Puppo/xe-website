Questa serata sarà dedicata alla sperimentazione di GitHub Copilot!  
Parteciperemo alla seconda edizione del GitHub Copilot Bootcamp, organizzato da Microsoft.

Insieme proveremo a seguire un workshop studiato appositamente da Microsoft per vedere e testare tutte le potenzialità di GitHub Copilot.

La serata prevede che ogni partecipante abbia il proprio portatile per seguire il workshop, un account GitHub e accesso alla versione free di GitHub Copilot.

Il resto delle cose da seguire le mettiamo noi :)

I posti sono limitati, perchè dovremmo prevedere banchi e prese di alimentazione per tutti.
