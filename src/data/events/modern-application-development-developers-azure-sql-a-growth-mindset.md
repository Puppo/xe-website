Partendo dalla definizione di "Modern Application", andremo a discutere di come Azure SQL si sia evoluto per essere una scelta perfetta per le applicazione moderne, qualsiasi sia il linguaggio o la piattaforma utilizzata.  
Vedremo le feature che sono state aggiunte negli ultimi anni ed analizzeremo le versioni Serverless e Hyperscale per vedere come la possibilita di effettuare Scale-Out sia ormai strettamente integrata nella soluzione, insieme a numerose altre funzionalita che rendono Azure SQL "batteries included", adottando questa famosa citazione da Python.  
Un po di esempi pratici, un po di novita, e anche una bella discussione sul cosa significhe essere uno sviluppatore a tutto tondo. Database compreso.
