Le Minimal API sono una delle novità più interessanti di .NET 6.0. Ma sono davvero così minimali? Ha senso utilizzarle in scenari complessi? In questa sessione analizzeremo le principali limitazioni che le caratterizzano e scopriremo come superarle, per capire se possiamo davvero adottarle in applicazioni reali.

E come nel (ormai) classico format online di XE, ci sarà ampio spazio per le domande ed il confronto.
