Dai suoi natali 21 anni fa JavaScript ne ha fatta di strada. Inizialmente pensato per rendere più dinamiche le pagine HTML (in Netscape Navigator) da parecchio tempo fa capolino anche lato server e, di fatto, per molti sviluppatori più giovani è il nuovo BASIC. E’ compagno inseparabile per tutti i browser, siano essi ospitati nei vostri computer con tastiera e mouse sia in quelli che portate in tasca o al polso. E’ una tecnologia abilitante, che rende possibile il moderno World Wide Web, ed è anche normato nelle specifiche ECMAScript. Nell’ultima parte del seminario sarà esaminata l’ASP.NET WebAPI, framework che rende semplice implementare web service.

DESTINATARI Il seminario – partendo dalle basi di JavaScript – è rivolto a tutti i Professionisti del settore dell’Informazione interessati alla recenti evoluzioni del Web.
