Come ogni anno, ad ottobre, presso il Consorzio Universitario di Pordenone, in via Prasecco 3/a, 1nn0va e xe.net organizzano il Visual Studio Saturday, il 21 ottobre 2017, dalle 9 alle 18.

In questo evento parliamo dell'ecosistema di .NET e di Visual Studio, e quindi ora di cose di cui parlare ce n'è veramente tante, tra .NET Core 2.0, ASP.NET Core 2.0, Visual Studio 2017, Visual Studio Code e il supporto a Windows, Linux, e Mac.
