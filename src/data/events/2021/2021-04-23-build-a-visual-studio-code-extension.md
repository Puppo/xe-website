Visual Studio Code è diventato in breve tempo uno dei tool di sviluppo piú popolari. Buona parte del suo successo è dovuto alla sua estensibilità che gli consente di poter supportare tantissimi tool e linguaggi di sviluppo. Ci sono estensioni per i linguaggi piú popolari, ma anche estensioni che consentono di testare un'API, trasferire un programma su Arduino, migliorare la leggibilità del codice, emulare VI e tanto altro. E se l'estensione che ti serve non esiste? Non preoccuparti, svilupparne una non è difficile! Segui questa sessione, con codice e demo, per scoprire come si fa.
