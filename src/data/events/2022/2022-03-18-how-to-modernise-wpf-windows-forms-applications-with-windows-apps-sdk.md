Con Windows Apps SDK Microsoft rilascia il nuovo framework per lo sviluppo di applicazioni desktop unendo la potenza dell’ecosistema di Windows alla flessibilità del nuovo runtime .NET. Oltre ad includere WinUI3, pensato per sviluppare la UI delle nuove applicazioni, Windows Apps SDK contiene molte funzionalità che è possibile integrare in applicazioni .NET esistenti per offrire un’esperienza moderna e consistente.
